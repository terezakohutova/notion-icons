# notion-icons

Portrait icons for the Claude Code agents in my workspace. Each agent has a
persona named after a historical figure, and each PNG here is that figure's
portrait, cropped to a circle and toned sepia. They live in a public repo only
so Notion can load them as page icons by URL.

## Using them

Point Notion (or anything else that takes an image URL) at the raw file:

```
https://raw.githubusercontent.com/terezakohutova/notion-icons/main/<agent>.png
```

for example `.../main/google-ads.png`. The file name is the agent's slug, so a
new agent needs a new PNG with its slug before its Notion card can show it.

## Where the images come from

Every portrait is a historical photograph, engraving or lithograph from
Wikimedia Commons. All of them are in the public domain: the authors died more
than 70 years ago, or the work is anonymous and old enough. The one exception
to "worldwide" is Ziegfeld, see the note in the table. None of the images are
AI generated.

My changes (circle crop, sepia toning, frame) are released under
[CC0 1.0 Universal](LICENSE): use the icons for anything, no attribution
needed. CC0 covers only my edits; the underlying portraits were never mine to
license and stay public domain.
